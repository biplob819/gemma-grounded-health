# V3.7 — v3b scoring: the pre-registered main_v3b run and its primary test

**Wave 7 (OWNER D-66, D-70; numbering D-72; rulings OWNER D-73). Depends on:** V3.6. **Unblocks:** the release decision (asked before any Hugging Face release).

## Why
configs/eval_plan_v3b.yaml registers one scoring run (main_v3b) and one primary test: v3b minus v2 on the headline over the shared 1,000 PQA-L cases. V3.6 froze the selected checkpoint (checkpoint-250, adapter 0537933d…, Q4_K_M 2befee83…) and committed both hashes. v3b's Q4_K_M parity missed X3.1's bar (0.924); the owner held scoring for a Q8_0 check, which passed (0.990), then ruled "Q4_K_M + Q8_0 extra" with a $5 cap (OWNER D-73).

## Design
- **Q8_0 check (RBS-03).** `scripts/v3b_q8_parity.py` reuses the committed bf16 replies of v3b's registered parity and asks ft3b-Q8_0 behind llama-server for its replies on the same 500 dev prompts; `docs/measurements/v3b/parity_q8_0.json` and its generations. Exploratory; the registered parity stays `parity.json`.
- **Run (RBS-01).** `uv run evalkit run configs/evalkit_v3b.yaml --task configs/tasks/pubmedqa_cit.yaml --n 1000` (EvalKit 0.4.0, Luna extracting, Sol judging, seed 7, `max_cost_usd: 5`). v3b-Q4_K_M (`ggh serve --model ft3b`, 8086) is the registered model; v3b-Q8_0 (`--quant Q8_0 --port 8087`) the exploratory extra; base and v2 servers stay stopped, so their answers must come from the store. Estimates before the run: `ggh results estimate` $2.16–$4.31 for one new model (the plan's), so up to about $8.6 for two by its upper bound; v3's actual cost was $1.82 for one, so about $3.6–$4 is expected; EvalKit's uncached dry run $44.40 (`docs/measurements/v3b/main_v3b_dry_run.json`). The cap stops the run if reached; a higher cap would go back to the owner. Results to `docs/results/main_v3b/`, spend to the ledger.
- **Primary test (RBS-02).** As V3.5: `family_tests` with the plan (one pair, one metric, one judge; 10,000 resamples, seed 7; Holm over one). "Improves" only if v3b's headline is above v2's and the interval excludes zero, else a tie. Guardrails: citation precision ≥ 0.70, aim-citation rate ≤ 0.10. Stretch: 0.404. Reported beside it, as the plan says: the label distribution and answer length, the copy share and the headline among non-copied answers (copy similarity < 0.9 to every cited sentence), with the near-copy share (≥ 0.7) added and V3.6's caveat that the copy measure misses verbatim cut-down extractions. v3b-Q8_0 minus v3b-Q4_K_M and v3b-Q8_0 minus v2 are exploratory.

## Result
- main_v3b (`r-66616600de17`, $3.47; the $5 cap raised to $8 by OWNER D-74 after EvalKit's up-front reservation stopped the citation batch): headline base 0.404, v2 0.329, v3b-Q4_K_M 0.503, v3b-Q8_0 0.541 (exploratory).
- Primary test: v3b minus v2 +0.174 [+0.147, +0.202], p 0.0002: **v3b improves on v2**. Guardrails pass (citation precision 0.873, aim-citation rate 0.032). Stretch reached (0.503 ≥ 0.404; v3b minus base +0.099 [+0.061, +0.138], exploratory). Label accuracy unchanged (0.677 vs 0.678); groundedness 0.729 vs 0.493.
- Beside it: copy share 0.191 (v2 0.107, base 0.271); the headline among non-copies 0.461 (v2 0.283, base 0.306). v3b's answers restate cited result sentences closely; the copy measure misses verbatim cut-down extractions (V3.6). 4 cited sentences went unjudged (2 per v3b model).
